# Defenses

01_adversarial_data_augmentation is the text analogue of the vision repo's PGD-AT/TRADES notebook: it generates HotFlip adversarial examples, keeps their original (correct) label rather than the flipped one, mixes them with clean examples, and fine-tunes a copy of the model on the combination. Evaluated on a held-out set never seen during augmentation, restricted to examples the model already classifies correctly. The result cuts HotFlip's attack success rate substantially (83.3% to 57.6%) but does not generalize to Synonym Substitution, a different attack family (16.7% to 18.2%, slightly worse), and costs clean accuracy (90.0% to 82.5%). The same lesson as adversarial training in the vision and audio repos: robustness learned against one attack family does not transfer to a different one.
